## 1. Pfleger-Verwaltung

> Erstellt User Stories für die Verwaltung von Pflegekräften: mindestens Anlegen, Anzeigen, Ändern, Löschen.

### User Story 1: Pflegekräfte verwalten

**User Story**

>Als Wohnbereichsleiter möchte ich Pflegekräfte verwalten können (anzeigen, anlegen, ändern und löschen), 
>um die Personaldaten im Pflegeheim aktuell zu halten und den Personaleinsatz effizient organisieren zu können.
> 

**Akzeptanzkriterien**

| Nr. | Kriterium                                                                                          |
|-----|----------------------------------------------------------------------------------------------------|
| A_1 | Alle vorhandenen Pflegekräfte werden mit ihren relevanten Stammdaten in einer Übersicht angezeigt. |
| A_2 | A_2 Neue Pflegekräfte können mit vollständigen Stammdaten angelegt werden.                         |
| A_3 | Bestehende Stammdaten von Pflegekräften können geändert werden.                                    |
| A_4 | Nicht mehr benötigte Pflegekräfte können gelöscht werden.                                          |
| A_5 | Pflichtangaben werden beim Anlegen und Ändern geprüft.                                             |
| A_6 | Änderungen (Anlegen, Bearbeiten, Löschen) werden nach dem Speichern in der Übersicht sichtbar.     |
| A_7 | Alle Änderungen bleiben auch nach Neustart der Anwendung erhalten.                                 |
| A_8 | Nur berechtigte Nutzer können auf die Pflegekräfte-Verwaltung zugreifen.                           |


**Tasks**

| Nr. | Task                                       |
|-----|--------------------------------------------|
| T_1 | Modelklasse für Pflegekräfte erstellen.    |
| T_2 | Datenbanktabelle für Pflegekräfte anlegen. |
| T_3 | DAO für Pflegekräfte erstellen.            |
| T_4 |View für die Übersicht aller Pflegekräfte erstellen.|
| T_5 |Eingabemasken für Anlegen und Bearbeiten ergänzen.|
| T_6 |Validierung der Pflichtfelder umsetzen.|
| T_7 |Controller-Logik für Anzeigen, Anlegen, Ändern und Löschen erstellen.|
| T_8 |Löschbestätigung implementieren.|
| T_9 |Aktualisierung der Übersicht nach Änderungen sicherstellen.|
|T_10 |Einbindung des Pfleger-Moduls in das Hauptfenster ergänzen.|

**Testfälle**

**TF1:**

|Pflegekräfte anzeigen |                                            |
|---|--------------------------------------------|
| **Vorbedingung** | Der Nutzer hat das Pfleger-Modul geöffnet. |
| **Testschritte** | _                                          |
| **Erwartetes Ergebnis** | Alle gespeicherten Pflegekräfte werden mit vollständigen Stammdaten in einer Übersicht angezeigt.                                           |

**TF2:**

|Neue Pflegekraft anlegen | |
|---|---|
| **Vorbedingung** |Der Nutzer hat das Pfleger-Modul geöffnet. |
| **Testschritte** | 1.Nutzer gibt alle erforderlichen Stammdaten ein.<br/>2.Nutzer speichert die neue Pflegekraft.|
| **Erwartetes Ergebnis** |Die neue Pflegekraft wird gespeichert und in der Übersicht angezeigt. |



**TF3:**

|Pflichtfelder fehlen |                                                                                          |
|---|------------------------------------------------------------------------------------------|
| **Vorbedingung** | Der Nutzer hat das Pfleger-Modul geöffnet.                                               |
| **Testschritte** | 1.Nutzer lässt mindestens ein Pflichtfeld leer.<br/>2.Nutzer versucht zu speichern.           |
| **Erwartetes Ergebnis** | Es erfolgt ein Hinweis auf fehlende Pflichtangaben. Eine Speicherung findet nicht statt. |

**TF4:**

|Pflegekraft ändern |                                                                                                              |
|---|--------------------------------------------------------------------------------------------------------------|
| **Vorbedingung** | Der Nutzer hat das Pfleger-Modul geöffnet und mindestens eine Pflegekraft ist vorhanden.                     |
| **Testschritte** | 1.Nutzer wählt eine Pflegekraft aus.<br/>2.Nutzer ändert Stammdaten.<br/>3.Nutzer speichert die Änderungen. |
| **Erwartetes Ergebnis** | Die geänderten Daten werden gespeichert und in der Übersicht aktualisiert angezeigt.                         |

**TF5:**

|Pflegekraft löschen |                                                                                                                 |
|---|-----------------------------------------------------------------------------------------------------------------|
| **Vorbedingung** | Der Nutzer hat das Pfleger-Modul geöffnet und mindestens eine Pflegekraft ist vorhanden.                        |
| **Testschritte** | 1.Nutzer wählt eine Pflegekraft aus.<br/>2.Nutzer startet den Löschvorgang.<br/>3.Nutzer bestätigt das Löschen. |
| **Erwartetes Ergebnis** | Die Pflegekraft wird gelöscht und nicht mehr in der Übersicht angezeigt.                                        |

**TF6:**

|Löschvorgang abbrechent | |
|---|---|
| **Vorbedingung** |Der Nutzer hat eine Pflegekraft ausgewählt.|
| **Testschritte** |1.Nutzer startet den Löschvorgang.<br/>2.Nutzer bricht die Bestätigung ab. |
| **Erwartetes Ergebnis** |Die Pflegekraft bleibt unverändert gespeichert.|

**TF7:**

|Speicherung nach Neustart prüfen | |
|---|---|
| **Vorbedingung** |Eine Pflegekraft wurde angelegt, geändert oder gelöscht.|
| **Testschritte** |1.Anwendung schließen.<br/>2.Anwendung neu starten.<br/>3.Pfleger-Modul öffnen. |
| **Erwartetes Ergebnis** |Alle Änderungen (neu, geändert, gelöscht) sind weiterhin korrekt gespeichert |
